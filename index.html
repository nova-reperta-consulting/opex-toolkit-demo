How to use this

The map answers what exists and how to run it. The sandbox answers what the output looks like. Between them you should be able to pick an analysis and start it on your own engagement.

Step 1
Open the map and find the analysis that fits your question.
Step 2
Read its panel: what it needs before you start, and the prompt that kicks it off.
Step 3
Open the same analysis in the sandbox to see what it produces.
Step 4
Install the plugin the panel names, and run it on your own team.
